# 偏移瓦片坐标系接入架构(GCJ-02 实战沉淀)

本文沉淀 GCJ-02(高德)接入的完整架构、数值账与教训,作为未来接入其他偏移
瓦片系统(BD-09、厂商私有偏移等)的参考模板。与 `multi-tile-schemes.md` 的
分工:那篇讲"四层坐标不许混"的通用原则,本篇讲**偏移场存在时渲染配准的
具体机制与踩过的坑**。

判据锚点:`docs/northstar/imagery.md` V11/V12/P5/P6。
数值守卫:`tests/unit/content/test_computed_imagery_uv_risk.cpp`(进 ctest)。
历史脉络:`206b10bf8`(引擎侧)→ `aa99a4ac5`(页存储真机点亮)→
`80892aca1`(四角仿射双管线)→ `f06117978`(跨界白面闸)→
`926271866`(旧称 `mappedRaster`、现为 Direct raster fallback 的回落路收官)。

## 1. 问题本质:偏移场的三个特征量

接入任何偏移瓦片系统,先量出这三个数,它们决定每一层的方案选型:

| 特征量 | GCJ-02 实测 | 决定什么 |
|---|---|---|
| **幅度** \|δ\| | ~500m(中国境内) | 能否忽略(≥某 zoom 亚像素则整段免处理);scale-bias 类补偿是否够用 |
| **梯度/曲率** | 主项 `20·sin(6πx)·⅔`,周期 ⅓°≈37km,折算 ~13m | 单瓦仿射近似的误差上界:`min(曲率·s²/8, 2×幅度)`,决定"每瓦几个系数"够不够 |
| **边界形态** | 硬矩形框(72.004/0.8293/137.8347/55.8271°),框外恒 0,**阶跃** | 跨界瓦片是所有连续近似的死穴,必须单独闸 |

GCJ 的关键结论(risk test 钉死):**每瓦仿射对境内全 zoom 亚像素**
(最坏 z10~11 约 0.16~0.24px,恰是瓦片跨度≈正弦周期的共振区);跨界瓦片
4.52px(境外侧)。BD-09 类系统接入时先复算这张表,别沿用 GCJ 的结论。

## 2. 架构分层(自下而上)

### 2.1 坐标变换层:`Gcj02CoordinateTransform`

- `fromWgs84(点)`:境外原样返回(硬阶跃,无羽化——见 §5 不足)。
- `boundRectangleFromWgs84(矩形)`:**区间算术保守包围盒**。8×8 分格 +
  每步 `nextafter` 外扩 + `sinInterval` 处理周期极值点。保证"变换后矩形
  必被包住",供 fetch 范围/details 矩形使用。**保守盒只许喂覆盖判定,
  不许喂采样配准**(过估会直接变成像素错位,踩过)。
- `crossesChinaBounds(矩形)`:「矩形内同时存在被变换与不被变换的点」,
  全内/全外均 false。是所有"连续近似失效"场景的统一闸。

### 2.2 投影枚举层:`RasterOverlayProjection` 加第三态

`Geographic / WebMercator / Gcj02WebMercator`。核心收益:把原先散在 5 处
的投影 switch 收拢,**新偏移系统加枚举态后编译器替你找出全部分支**。
`projectWorldPositionForRasterOverlay` 是唯一的点投影入口——烘焙 texcoord、
四角仿射、details 矩形全走它,新系统在此一处接入即全链生效。

details 数组约定:`[0]` 恒为地形 scheme 投影,影像投影 append 到后位;
texcoord set 与之对齐(set 1 = 影像投影)。**任何按 `[0]` 硬取矩形的代码
都是 bug 温床**(TileSurfaceClip 曾因此埋雷)。

### 2.3 渲染配准层:一句总纲

> **编址归源空间,剔除/测距归世界空间,采样配准逐点/逐角精确,
> 覆盖判定才许用保守盒。**

四类机制各司其职:

| 机制 | 精度形态 | 用在哪 |
|---|---|---|
| 逐顶点烘焙 texcoord(`rewriteProjectionTexCoords`) | 逐点精确 | 真实网格稳态采样 |
| 页存储 D 方案(cell 网格=**源瓦片网格**,origin/span 承载错位 + 祖先寻址相位) | 编址精确 | 页存储寻址;标准源恒退化(`isDegenerate`)= 零回归判据 |
| **四角仿射** `computeGeomAffine`(几何 UV→源格,四角逐点投影,交叉项保留) | 每瓦 6 系数,瓦内二阶弯曲 ~2m 亚纹素;**相邻瓦共享角点 → 瓦界按构造连续** | 共享位移模板路径(模板 UV 不绑经纬,烘焙不可用) |
| clipUv 窗口 remap(模板态 set 0 在 VS remap;其余 set 在 FS 补同一 scale-bias) | 窗口级 | 祖先回退/模板态的所有采样消费者 |
| worldOffset(瓦片中心单 δ) | 阶跃近似 | **只喂**视锥剔除/测距;跨界瓦片直接放弃剔除(`crossesGcjBoundary`) |

## 3. 数值账(实测,非估算)

- **CPU warp 判死**:合成期把源瓦重采样到对齐网格 = 598µs/页(host
  Release,Android 大核 ~1.2ms)× 8 页/帧预算 → 太贵。⚠️ Debug 数字虚高
  13×,性能判断先查 `CMAKE_BUILD_TYPE`。
- **四角仿射成本**:3 次点投影/瓦,µs 级,每帧重算不缓存。
- **float32 精度**:所有绝对量(经纬、mercator y、×R)必须在 CPU 双精度
  预算成每瓦常数,shader 只见归一化小量,则 float32 贡献 ~0.001px。
  ⚠️ 投影输出单位 = 弧度 × 长半轴(米):曾漏 R 因子,被 risk test 以
  百万 px 级红当场抓获——单位混用是这类公式的头号雷。
- **保守盒过估**:~1e-4°(≈10m),z15 瓦片上约 0.9% 瓦宽。这就是它
  不许喂采样的原因。

## 4. 做得好的(值得复制到下一个系统)

1. **概念分离而非魔法偏移**:「世界几何坐标」与「影像源坐标」拆开,
   偏移由投影层显式承载。渲染层没有任何 `+0.005` 式硬编码。
2. **退化零回归设计**:每个机制都构造成"标准源下逐字符/逐位等于改造前"
   (placement 退化、相位恒 0、仿射轴对齐)。改造的回归验证 = 对比标准
   路径像素 diff(实测 0.9%),不需要信任审读。
3. **四角仿射的瓦界构造连续性**:比"中心+梯度"拟合多出的关键性质,
   相邻瓦共享角点值相同,瓦界错缝在构造上不存在(真机 29.6m 错缝 ==
   矩形重叠量精确互证后根修)。
4. **风险预验方法论**:动 shader 前先在 host 用双精度 oracle 钉死近似
   误差上界(risk test 三刀:约定复现 3e-8 / 仿射亚像素 / float32
   0.001px),把"能不能这么近似"从争论变成数字。
5. **像素证据裁决,不信日志**:特性"生效"的判定靠 20× 放大偏移量看屏幕
   是否变化——曾有 `proj=gcj-merc` 日志全对、provider 行为全对、屏幕
   逐像素不变的完整假象(PageStore 绕过 Direct raster fallback 通路)。

## 5. 不足与教训(诚实清单)

1. **⚠️⚠️ 上屏路径枚举不完备是本案最大反复来源**。同一个"模板态 set 1
   没 remap"的病灶,先后在 PageStore 路(aa99a4ac5 修)和 Direct raster
   fallback 路(926271866 才修)各暴露一次;中间还有一次"已修"静态误判被真机
   推翻——只审了主路没审回落路。**接入新系统时必须逐条过上屏路径清单**:
   PageStore(逐瓦/实例化)、Direct raster fallback、矢量层、fill 代理、
   glTF 真实网格,× GLSL/MSL 两份。缺一条,症状就是"稳态对、某瞬间错"。
2. **配准逻辑无单一治理点**:采样链收拢进了 `eePageStoreCompose`,但
   "UV 从哪套 set 取、要不要补窗口 remap"仍散在各 FS 手写。五次 commit
   全是在补"上一次漏的那条路"——结构性成因。
3. **中国框四常数未与高德实际偏移域比对**:开源惯例值,假设未验证。
   若厂商实际域不同,跨界判定位置整体平移。新系统接入时把"边界从哪来、
   怎么验"列为一等问题。
4. **跨界瓦片处置未拍板**(V12 🔒):仿射原理性代表不了阶跃,4.52px
   留在境外侧。候选:接受 / 跨界瓦片挡回烘焙路径。
5. **遗留债**:iOS Geographic 第四态未接;fill 代理 UV 二阶(P6);
   z≤5 模板纬度线性残差(P5,标准底图同样命中);Metal 全程仅源码一致性
   (T-P6:host 无 shader 执行守卫);上采样链当前生产不可达,复活时其
   窗口重归一化需与本文口径同步。

## 6. 新偏移系统接入 checklist

1. 量 §1 三特征量(幅度/梯度/边界形态),先判"哪些 zoom 可整段忽略"。
2. 写点变换 + 区间算术保守盒 + `crossesBounds`;单测含逐边跨界/包住全框/
   空矩形,并**故意破坏验守卫会响**。
3. `RasterOverlayProjection` 加枚举态,编译器驱动扫全部 switch;
   `projectWorldPositionForRasterOverlay` 接入后烘焙/四角仿射自动生效。
4. 扩展 risk test:新投影的仿射误差上界 + float32 全 zoom 阶梯。
5. **逐条过上屏路径清单**(§5.1),每条确认"稳态 + 过渡态"两个状态的
   UV 空间口径;改动原子落地(VS remap 与 FS 消费者同 commit)。
6. 边界阶跃:跨界瓦片进 `crossesBounds` 闸(视锥剔除放弃,防合批白面),
   退化量化后交用户拍板。
7. 验收:标准路径像素 diff 零回归;偏移路径 20× 放大逼出静默失效;
   真机过渡场景(低空拉高空盯过渡帧)单列验收——稳态验收不覆盖它。

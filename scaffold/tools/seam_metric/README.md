# 接缝「漏天缝」客观度量

把「瓦片接缝观感不佳」从肉眼判断变成**可计数指标**，让接缝类改动能像加载期一样
做 A/B（见 [`tools/load_ab`](../load_ab/README.md)）。

## 为什么需要它

接缝是运动期暂态、位置随机、单帧眼看极易误判。本次排查就连续踩了两次：

1. 把 `DebugImageryProvider` 自己画的 **1px 白色瓦片边框**当成了缝；
2. 凭一张截图判定 fill 代理是横断的成因，A/B 直接证伪。

## 原理

一列像素自上而下扫，第一个非天色像素即该列地平线。**地平线以下再出现天色像素 =
地面开了缝**，天/雾从缝里透出来。天色取每帧顶部 5% 的中位色（雾随视角变，不能
写死常量），地平线下 30px 内不计（抗锯齿与雾过渡带）。

## 用法

```bash
tools/seam_metric/seam_leak.py <截图目录> [更多目录...]
```

每个目录取其中的 `s*.png`，输出漏天像素合计 / 每帧均值 / 最差帧。截图用
`adb exec-out screencap -p`，运动脚本参考 `tools/load_ab/collect.sh`。

## 已采基线（2026-08-03，掠视 1.5km→120km 缩放，release，冷缓存）

| 变体 | 漏天像素/帧 | 相对基线 |
|---|---|---|
| 封缝带 `0.30` | **53.0** | **0.53×** |
| 基线：封缝带 `0.03` | 100.8 | 1.00× |
| 「斜裙」尝试（已撤） | 640.1 | 6.4× ❌ |
| 关掉 fill 代理 | 1333.1 | 13.2× ❌ |

三条结论都由这张表定的，不靠观感：

- **fill 代理是承重的**，关掉漏天缝涨 13 倍（它在堵洞，不是接缝的成因）；
- **把裁剪矩形外的顶点压到椭球面当「裙」是回归**（斜裙铺开一整格宽，粗祖先一格
  可达 ~10km，翻出大片平板），已撤回；
- **横向封缝带 0.03 → 0.30 有效**，但那是把覆盖量调大，治标。

⚠️ 跨**构建变体**比较要小心：关掉卫星影像改走 Debug 棋盘时，细分深度由 debug
图层驱动（实测到 z16+），可见瓦片数与 LOD 跨度都变了，与卫星档不可直接比。
同一档内比才有效。
